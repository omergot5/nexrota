<objective>
Put the engine's own load number on the two screens that claim to show fairness, and make the browser serve it.

Plan 01-01 fixed the arithmetic: `balanceWorkload` now ranks by load, `buildResult` now scores load variance, and `fairness` carries `perGuard[].load`, `loadMean`, `loadMax`, `loadSpread` and `perShiftLoad` explicitly so that this plan can render them without re-deriving anything. But the supervisor's screen still shows the old unit: `SmartAssign.jsx`'s "חלוקת העומס המוצעת" card is *named* load and *renders* shift count, and the "ציון הוגנות" tile's hint reports a count gap directly under a load-derived score — the exact self-contradiction Research §Pitfall B and §Pitfall A warn about ("0 משמרות פער" printed under a score of 98).

This plan closes the display half of FAIR-02, pins FAIR-05 so the participant's number can never drift from the engine's, and bumps the service-worker cache version so the fixed bundle is actually the one a returning browser runs (FAIR-06).

Purpose: the phase's goal line is "נטל, בכל מנוע **ובכל מסך**". An engine that measures correctly behind a screen that reports the old unit has not fixed anything a user can see — and per the locked decision, a transparency feature reporting a wrong figure is worse than no transparency.

Output: a supervisor screen that shows the number the engine divided by, a standing `npm test` gate that fails the moment the participant screen and the engine disagree, and a released service worker that cannot resurrect the old formula.

**Decision IDs** (assigned in `01-01-PLAN.md` from `01-CONTEXT.md` § "הכרעות נעולות שרלוונטיות לפאזה", which is a table without IDs — reused verbatim here so both plans cite one set):
- **D-01** — load is the only fairness metric in the product (this plan: the display half)
- **D-02** — the constants are re-derived from the roster, not token-swapped (this plan: the tag's noise floor)
- **D-03** — the participant sees the same number the engine divided by (this plan owns it)
- **D-04** — absolute determinism: no RNG, no clock dependence, no DB row-order dependence
- **D-05** — the design system is mandatory on every screen this phase touches (this plan owns it)
