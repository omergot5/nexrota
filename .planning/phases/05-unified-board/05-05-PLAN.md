<objective>
Close UAT gap **G-05-1** (BOARD-04 / D-13): a naive first-time viewer could not tell the board's
two signals apart, because they collapse into one glyph and the text that would disambiguate them
is unreadable.

Two verified code defects, per `.planning/debug/board04-comprehension-confusion.md` (AND-gate —
fixing only one leaves the criterion failing):

1. **Icon overload.** The `מחוץ למנוע` badge on a timeless row and the qualification-block corner
   badge on a blocked assignee's avatar render the same padlock geometry. The viewer is asked to
   distinguish "this item has no clock time" from "this person can't do this item" and the board
   answers both with one symbol.
2. **Illegible label.** `People`'s blocked branch derives its font size from the avatar's pixel
   size, and the board calls it at avatar size 24 — so the qualification words render at ~6px
   inside a 24px circle. This is a legibility regression against the AssignView precedent that
   D-09 requires be reused verbatim (there the same words are a separate, normally-sized row).

Plus one contributing copy defect: the empty state invites the viewer toward an action name that is
not clickable in that copy block and is not a productive first step.

Purpose: restore D-13's comprehension criterion by making the existing signals *distinguishable and
readable* — **not** by adding a legend or onboarding. **D-14 stays intact**: this plan adds no key,
no legend, no tour, no explanatory chrome. It changes one glyph, one label's size and placement, and
one sentence of copy.

Output: a distinct timeless glyph reserved to that one meaning; the padlock reserved to
qualification blocking alone; the `לא כשיר/ה` words legible at the board's own label size; a
self-consistent empty state; and a deterministic Node gate wired into `npm test` that fails if any
of those regress.
</objective>
