## חוזה ה-API של ResourceGrid (תוכניות 06-02 ו-06-03 מסתמכות עליו — אסור לשנות אותו בהן)

```
ResourceGrid({
  rows = [],                      // פלט buildResourceRows: [{category, icon, days:[{date, items}]}]
                                  // שורה רשאית לשאת pending:true
  dates = [],                     // מחרוזות ISO — עמודה לכל תאריך, באורך כלשהו
  guards = [],                    // [{id, name}] — לפתרון מזהה → שם פרטי
  firstColLabel = "עמדה / קטגוריה",
})
```

- מחזיר `null` כש-`rows.length === 0` — המצב-הריק שייך לקורא, לא לרכיב
- פריט בתא רשאי לשאת `pending: true` — נצרך על ידי 06-02
- `mode` **אינו** prop: נקרא בתוך הרכיב מ-`subscribeTerms`/`termProfile` (D-07)
